Support

LoopTopic01 is a daily habit challenge app with XP and streaks for short challenge loops.

Quick help

  • Use a single challenge at a time and complete the progress ring daily.
  • If rewards feel incorrect, clear app cache by reinstalling the app.
  • Disable notifications in iOS Settings if you only want manual use.
  • If you see an issue on launch, restart your phone and reopen the app.

Contact: support@alexmitre.com with the iOS version and app version.
