Still

Support

Still is a work-hours focus lock you start yourself. It does not block other apps on the system.

Quick help

  • Start a 25, 50, or 90 minute session from Today.
  • Type one intention. It stays on this iPhone.
  • Stats show streak and weekly minutes.
  • Change language in Settings. English, Spanish, and French are included.
  • Turn off 7:00 and 19:00 reminders in the app Settings or in iOS Settings.
  • Deleting the app removes session history.

Contact: support@alexmitre.com with the iOS version and app version.
