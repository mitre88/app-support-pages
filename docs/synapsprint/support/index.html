SynapSprint

Support

SynapSprint is an offline cognitive decision game. Each short sprint presents a rule, streams words, and rewards fast accurate taps.

Quick help

  • Read the rule before each sprint, then tap target words and ignore non-targets.
  • Use the map to unlock later cognitive chapters as you improve.
  • Adjust locale, sound, haptics, and comfort cadence in Settings.
  • Progress is stored only on your device; deleting the app removes it.

Contact: support@alexmitre.com with the iOS version and app version.
